2) Explain one debugging example.
One example I ran into was a KeyError: 'grade' that I ran into the first time I ran the program with the provided main().
When I ran the program it started fine and loaded the students and printed the summary and grade distribution. Then it
crashed when it reached the "Top 5 Students" section. How I figured out the error. The traceback pointed to the line in main()
that prints the top 5: print(f"  {s['name']:<20} {s['average']:.1f}  ({s['grade']})"). A KeyError means the code asked a dictionary
for a key it doesn't have. main() was looking up 'grade' in 3 places: generate_report where the dictionary is built, and twice in write_report
where it's read. In my code I had it written as 'letter_grade' instead of 'grade'. I made the change and the program ran start to finish.
I also had smaller syntax errors that I caught as I was writing the functions. They were simple indention errors and expecting : and ).

5) Explain requirements.txt
 In a normal Python project requirements.txt list the outside packages the program needs such as packages installed with pip. This makes it easy for anyone who downloads the project
 to install everything at once with a simple terminal command: pip install -r requirements.txt. In grade_tracker.py requirements is empty because the program does not use any outside
 packages. The only module it imports is csv which is part of Python's built in library and doesn't need to be installed. The program reads data from the local student.csv and writes
 the results to grade_report.txt
