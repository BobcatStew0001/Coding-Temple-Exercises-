# Quote Generator

A simple Python script that displays a random inspirational quote each time it runs.

## Requirements

- Python 3.8+

## Setup

### Windows (PowerShell)
```
git clone <your-repo-url>
cd quote-generator
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### macOS / Linux
```
git clone <your-repo-url>
cd quote-generator
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

> Note: `requirements.txt` is empty because this project only uses Python built-in modules.

## Usage

```
python main.py
```

Example output:

```
"The journey of a thousand miles begins with one step." — Lao Tzu
```

## Deactivate the virtual environment

```
deactivate
```
