Coding Temple Exercises

A collection of practice exercises completed during my Coding Temple software engineering bootcamp. The work is primarily written in Python and is meant to build and reinforce core programming fundamentals.

About This Repo

Each file is a standalone exercise focused on a specific concept or skill. Many include comments explaining my reasoning, how I diagnosed a problem, or how I fixed it. The goal of the repo is practice and growth, so you may see exercises revisited or revised as my understanding improved.

Topics Covered
Variables and data types
Type conversion (int(), str()) and common TypeError / ValueError fixes
Reading user input with input()
String formatting and concatenation
Error types and debugging (SyntaxError, TypeError, ValueError, NameError)
Exception handling with try / except

Running an Exercise
Make sure Python 3 is installed:
bash
   python --version
Clone this repository and move into it:
bash
   git clone <repository-url>
   cd <repository-folder>
Run any exercise file:
bash
   python exercise_name.py
